# YOU CRM Prototype

This is a shareable preview package for the Youth Opportunities Unlimited CRM prototype.

## Quickest Way To View

Open this file in a browser:

```text
static-preview/index.html
```

This version is already built as a static HTML preview.

## Open In VS Code

1. Open the `YOU_CRM_share_package` folder in VS Code.
2. Open the VS Code terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local address shown in the terminal. It is usually:

```text
http://127.0.0.1:5173/
```

## Demo Logins

## Notes

This is a front-end prototype only. It uses sample data inside the app and does not connect to a real database.
